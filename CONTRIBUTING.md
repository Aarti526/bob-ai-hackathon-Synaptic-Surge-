# Contributing / Submission Instructions

This repo follows the Bob AI Hackathon submission template. Do not delete this file,
`submission.yaml`, or the top-level `docs/`, `demo/`, `presentation/` folders — the
automated validator and evaluators depend on them.

## Before submitting

1. Fill in every `# REQUIRED` field in `submission.yaml`.
2. Fill in the real team, problem, solution, and demo sections in `README.md` — search
   for `[` to catch any leftover placeholders.
3. Replace `demo/demo-video-link.txt` with a real, accessible video URL.
4. Add at least 3 screenshots to `demo/screenshots/`.
5. Add `presentation/slides.pdf` (or `.pptx`).
6. Push, then check the **Actions** tab for a green **Validate Submission** run.
7. Submit the repo URL via the entry form before the deadline.

## Repo structure

All source code lives under `src/` — see `src/README.md` for its internal layout and
`docs/setup-guide.md` for how to run it.
